Yang bisa dilakukan AzurePet

Sederhana di permukaan, tapi cukup dalam untuk model 3D buatanmu sendiri.

Model .glb milikmu

Format glTF binary maupun .gltf. Bisa beberapa file sekaligus, maksimal 12 karakter bersamaan.

4 animasi per karakter

Saat diam, saat jalan, saat di-drag, dan saat diklik — pilih sendiri dari animasi yang ada di file modelmu.

Klik, drag, bereaksi

Klik kiri memutar animasi khusus. Tahan dan geser untuk memindahkan. Klik kanan membuka menu.

Tetap ringan

30 fps saat bergerak, 20 fps saat diam, dan render benar-benar berhenti ketika karakter disembunyikan.

Selalu di atas

Karakter tidak tertutup jendela lain, dan di macOS tetap muncul walaupun ada aplikasi fullscreen.

Jalan otomatis

Atur ukuran, kecepatan, arah hadap, dan area jalan. Bisa juga jalan sendiri saat komputer baru menyala.

Cara pasang

Tanpa terminal. Cukup klik-klik seperti aplikasi biasa.

  1. Buka file .dmg yang sudah diunduh.
  2. Klik kanan ikon AzurePet di jendela itu, pilih Open, lalu Open lagi. (Jangan klik dua kali biasa — macOS akan menolak karena aplikasinya belum bersertifikat Apple.)
  3. Setelah terbuka sekali, AzurePet menyalin dirinya ke folder Applications dan terbuka lagi dari sana. File .dmg boleh dihapus, aplikasinya tetap ada.
  4. Berikutnya, buka lewat Launchpad atau Spotlight (⌘ + Spasi, ketik “AzurePet”).
  5. Kalau macOS 15 ke atas tidak menampilkan tombol Open: buka System Settings → Privacy & Security, gulir ke bawah, klik Open Anyway.

Pilih Apple Silicon untuk Mac M1/M2/M3/M4, atau Intel untuk Mac prosesor Intel. Ragu? Buka  → About This Mac, lihat baris “Chip” atau “Processor”.

  1. Jalankan file .exe yang sudah diunduh.
  2. Kalau muncul “Windows protected your PC”, klik More info lalu Run anyway.
  3. Installer memasang AzurePet untuk pengguna kamu sendiri — tidak butuh hak administrator.
  4. Setelah selesai: shortcut ada di Desktop, dan aplikasinya bisa dicari di menu Start dengan kata kunci AzurePet.

Ragu pilih yang mana? Buka Settings → System → About, lihat baris System type: kalau tertulis “64-bit operating system, x64-based processor” pakai 64-bit (x64); kalau “32-bit” pakai 32-bit (x86). Installer 32-bit tetap bisa dipasang di Windows 64-bit, tapi versi 64-bit lebih ringan. Pakai ARM64 hanya kalau perangkatmu ARM (Surface, Snapdragon).

  1. Klik dua kali file .deb.
  2. Software Center / GDebi terbuka → klik Install → masukkan password.
  3. Cari AzurePet di menu aplikasi.
  4. Butuh compositor aktif (GNOME, KDE, Cinnamon, dan Mint sudah aktif sejak awal) supaya latar karakter transparan.

Arch Linux, Manjaro, EndeavourOS — ada dua pilihan, pakai salah satu:

1 · Paket resmi Arch (.pkg.tar.zst)

  1. Unduh AzurePet-Linux-Arch-x64.pkg.tar.zst.
  2. Pasang lewat terminal: sudo pacman -U AzurePet-Linux-Arch-x64.pkg.tar.zst
  3. Atau klik dua kali file-nya lewat Pamac (“Tambahkan/Instal Paket Lokal”).
  4. Setelah itu AzurePet muncul di menu aplikasi dan bisa dihapus lewat pacman/Pamac.

2 · AppImage (tanpa memasang apa pun)

  1. Unduh AzurePet-Linux-x64.AppImage.
  2. Klik kanan → Properties → tab Permissions → centang Allow executing file as program.
  3. Klik dua kali → AzurePet langsung jalan. Tidak ada yang masuk ke sistem, tidak butuh sudo.
  4. Kalau muncul pesan soal FUSE: ./AzurePet-Linux-x64.AppImage --appimage-extract-and-run
  5. Ingin ikonnya masuk menu aplikasi? Pasang AppImageLauncher, lalu buka AppImage-nya sekali.

Distro lain (Fedora, openSUSE, Void, …) — pakai AppImage di atas; file yang sama jalan di distro apa pun.

Setelah terpasang

Buka aplikasinya, lalu:

  1. Klik + Tambah karakter (.glb)... dan pilih file model 3D milikmu (bisa juga diseret ke jendela pengaturan).
  2. Pilih animasi untuk diam, jalan, di-drag, dan diklik.
  3. Atur ukuran, kecepatan, dan area jalan. Selesai — karakternya langsung hidup di desktop.

Pertanyaan yang sering muncul

Apakah model 3D-nya disertakan?

Tidak. AzurePet tidak membawa model bawaan — kamu memakai file .glb milikmu sendiri. Animasi yang muncul di daftar juga otomatis diambil dari file model itu.

Kenapa Windows / macOS memberi peringatan saat pertama dijalankan?

Karena aplikasinya belum ditandatangani dengan sertifikat digital berbayar (Windows code signing dan Apple Developer Program). Peringatan itu soal identitas pembuat, bukan virus. Klik More info → Run anyway di Windows, atau klik kanan → Open di macOS.

Bedanya installer Windows 32-bit dan 64-bit apa?

Isinya aplikasi yang sama, bedanya mesin Electron yang dipakai. Yang 64-bit (x64) lebih ringan dan lebih cepat karena memakai arsitektur prosesor 64-bit secara penuh. Yang 32-bit (x86) bisa dipasang di Windows 32-bit maupun 64-bit, jadi pilih ini kalau kamu tidak yakin. Kalau Windows-mu ARM (Surface, Snapdragon), pakai yang ARM64.

Apakah aplikasi ini butuh internet?

Tidak sama sekali. Tidak ada koneksi ke server mana pun, tidak ada akun, tidak ada iklan. Model dan pengaturan hanya tersimpan di komputermu sendiri.

Berapa banyak karakter yang bisa dipakai sekaligus?

Maksimal 12. Setiap karakter berjalan sebagai jendela sendiri, jadi makin banyak karakter makin banyak pemakaian RAM. Dua sampai empat karakter biasanya paling nyaman.

Karakter tidak muncul, atau jendelanya hitam. Kenapa?

Biasanya driver kartu grafis. Coba perbarui driver VGA. Di dalam Remote Desktop, efek jendela transparan umumnya tidak jalan. Di Linux, pastikan compositor aktif.

Cara menghapus aplikasinya?

Windows: Settings → Apps → Installed apps → AzurePet → Uninstall. macOS: seret AzurePet dari folder Applications ke Trash. Linux Debian: sudo dpkg -r azurepet atau lewat Software Center. Linux Arch: sudo pacman -Rns azurepet. AppImage: cukup hapus file .AppImage-nya (tidak ada yang tertinggal di sistem). File .glb milikmu tidak ikut terhapus.
